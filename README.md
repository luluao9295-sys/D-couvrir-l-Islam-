# Découvrir l’Islam

Site pédagogique francophone pour découvrir simplement les bases de l’Islam : histoires des prophètes, cinq piliers, 99 noms, hadiths, invocations et prière.

Site public : https://luluao9295-sys.github.io/D-couvrir-l-Islam-/

Le contenu est présenté de façon progressive et sourcée. Les prophètes, les anges et Allah ne sont pas représentés par des illustrations.
